## Objetivo
Criar `docs/FONTES-OFICIAIS.md`: um registro, por item da §21, de **onde** está a resposta oficial (documento, versão,
seção/página, link, data de acesso) e o que o texto diz, com status honesto. É a base das decisões E2-S02 (cStat),
E2-S11 (assinatura) e E2-S12 (smoke). É **rascunho**: o agente encontra e cita; quem dá o item por conferido é o autor.
Nenhum código, teste ou doc existente é alterado.

Regras do documento (valem para todos os passos):
- **Nunca inventar link, número de NT, versão ou seção.** Se não achou, escreva `NÃO LOCALIZADO` + o que buscou.
  Link só entra se foi aberto nesta sessão (WebFetch/WebSearch) e a data de acesso é anotada.
- Status por item: `PENDENTE` (nada achado) · `FONTE LOCALIZADA` (link aberto, trecho citado) · `CONFERIDO PELO AUTOR`
  (só o autor marca). O agente nunca usa o terceiro.
- Citação curta (até ~2 linhas) do trecho relevante + a leitura proposta. Divergência com o CLAUDE.md → marcar
  `⚠ DIVERGE DO CLAUDE.md §x` e **não** editar o CLAUDE.md (vai para PARA-VOCE como [DUVIDA] no fim).
- Preferir fonte primária (portal da NF-e, NT, MOC, Ajuste SINIEF/legislação) a blog/fórum. Fonte secundária só como
  pista, rotulada `(secundária)`.
- Cada item lista "Afeta:" — os testes/subetapas que mudam quando o item for conferido.
