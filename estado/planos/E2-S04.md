## Objetivo
Criar no domain o value object `BlobRef(chave, sha256)`, um utilitário puro de SHA-256 e a porta
`BlobStore` (`gravar(chave, bytes, sha256) → BlobRef`, `ler(BlobRef) → Optional<byte[]>`), mais
`BlobStoreEmMemoria` em `adapter-fake` (DA-4). É a base para a E2-S07 (adapter grava o bruto) e a E3-S05 (MinIO).
Regras: gravar a mesma chave com o mesmo hash é no-op idempotente; com hash diferente é rejeitado; hash
informado que não bate com os bytes é rejeitado; bytes são copiados na entrada e na saída (defensivo).
